Aide

Quelque chose ne marche pas, une carte manque, ou vous avez une idée pour l'appli ? Voici comment me contacter.

{{icon:lifebuoy}}

Le plus simple, c'est GitHub. Ouvrez un ticket avec votre question ou le problème rencontré, et je vous répondrai là-bas. Vous pouvez aussi consulter les tickets existants avant. Il faut un compte GitHub (gratuit) pour écrire. Vous pouvez écrire en français.

Ce qui m'aide à corriger un problème

  • Votre appareil et la version du système, par exemple « Galaxy Z Fold 6, Android 16 » ou « iPhone, iOS 27 ».
  • La version de l'appli (sur Android, elle est indiquée dans les Réglages).
  • Ce que vous avez fait, ce que vous attendiez et ce qui s'est passé. Une capture d'écran aide beaucoup.
  • Pour une carte mal reconnue, le code imprimé en bas à gauche, par exemple OGN • 066a/298 • FR.

Questions fréquentes

Une carte est reconnue dans la mauvaise version.

Touchez la puce avec l'extension et le numéro sous la carte scannée pour voir toutes ses versions, puis choisissez la vôtre. Une puce marquée « ? » signifie que l'appli n'a pas pu départager les versions toute seule.

La langue détectée est fausse.

Touchez la puce avec le drapeau sous la carte scannée pour la changer, ou choisissez une langue fixe à la place d'Auto pour les prochains scans.

Une carte apparaît bannie alors qu'elle ne l'est pas dans ma région.

Les bannissements peuvent varier selon la région de compétition. Choisissez votre région dans les Réglages : la liste des bannissements se met à jour aussitôt.

Une nouvelle extension ou une carte promo manque.

L'appli met à jour sa liste de cartes à l'ouverture dès que de nouvelles données sont disponibles. Si une carte manque toujours, ouvrez un ticket avec son nom et son code.

Comment transférer ma collection sur un nouveau téléphone ?

Dans les Réglages, exportez une sauvegarde, puis restaurez-la sur le nouvel appareil. Le même fichier fonctionne sur Android et iOS.

Confidentialité

ScanRift n'a pas de compte et ne collecte aucune donnée personnelle. Lisez la politique de confidentialité.
